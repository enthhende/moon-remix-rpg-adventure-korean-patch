## v2.0에서 완료한 대표 검증

- 일본판 Rev 1 원본에서 최종 이미지를 두 번 독립 재빌드해 바이트 일치
- 정방향 xdelta를 두 번 독립 생성해 바이트 일치
- 깨끗한 원본에 배포 패치를 적용한 결과가 exact v2.0 BIN과 일치
- 내부 검증용 역방향 복원이 깨끗한 원본과 일치
- 수정한 Mode2/Form1 섹터의 EDC/P/Q ECC 재계산·검증
- 선언한 변경 범위 밖 차이 0바이트
- 콜드 부팅, 타이틀과 일반 Game Start/Continue
- 숨겨진 메뉴 진입, 경고·페이지 이동과 타이틀 복귀
- 보너스 자료관 대표·전체 순서와 48화면 경계
- `용의꼬리(미사용 엔딩)` 대표 진행과 자동 복귀
- `소년과 할머니`의 집 밖→집 안 연결과 안전 출구
- 일반 메모리카드 생성·저장·로드·리셋·Continue
- 이름의 `♥`·`@` 표시, 특수문자 뒤 조사·호격
- 데이터 삭제 질문과 무츠지로 호칭
- Galmuri 대문자 자간, MD 실제 폭 가운데 정렬과 일반 대화 회귀
- `타마야 공방` 표시·진입, 엔딩 raw 01799 표시·종료·다음 대화 진행

## 긴 이름 검증 범위

PS1 저장 데이터에는 긴 이름이 없어 O45/O46의 모든 엔딩 페이지를
최대 이름으로 직접 재생하지는 못했습니다.

- PS1 실제 파서 규칙으로 최대 7자 이름을 넣어 계산한 정적 검사:
  모든 대상 페이지가 3행 이하, 행당 15코드 이하
- 같은 문구와 줄바꿈을 적용한 Switch판 긴 이름 런타임: 사용자 확인
- PS1 이름 `민지`로 raw 01799 세 행, 완전한 마지막 문구, 잔여 바이트
  없음, 다음 대화 진행: 직접 확인

Switch 결과는 보조 증거이며 PS1 긴 이름 런타임으로 표기하지 않습니다.

## 저장과 savestate

일반 메모리카드 저장 형식은 유지됩니다. 다만 중요한 저장은 패치 적용 전
복사해 두세요. 서로 다른 패치 BIN에서 만든 savestate는 코드와 RAM 상태가
섞일 수 있으므로 지원하지 않습니다. 게임 내 저장 뒤 에뮬레이터를 완전히
종료하고 새 CUE로 콜드 부팅하는 방식을 권장합니다.

## 호환성 제보

다음 정보를 포함하면 호환성 표를 근거 있게 갱신할 수 있습니다.

- 한국어 패치 버전과 패치 직후 BIN SHA-256
- 에뮬레이터 이름·버전, 또는 본체·부팅 환경
- EBOOT.PBP라면 변환 도구와 설정
- 부팅, 음원, 저장, 맵 전환, MD 재생, 추가 콘텐츠와 엔딩 여부
- 문제가 생긴 정확한 시점과 재현 순서

원본·완성 BIN/CUE, BIOS, 메모리카드 전체 덤프와 savestate는 첨부하지
마세요.
