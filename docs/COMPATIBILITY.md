# 호환성 및 검증 범위

## 현재 표기

**에뮬레이션 검증 완료 / 실기 미검증**

이 표현은 에뮬레이터에서 성공했다는 사실을 다른 실행 환경의 성공으로
확대하지 않기 위한 것입니다.

| 실행 환경 | v1.0 상태 | 비고 |
|---|---|---|
| Mednafen PSX `013d057` | 검증 | 장편 자연 플레이, 저장, 음원, 주요 이벤트, 진엔딩 |
| 일반 PS1 메모리카드 | 검증 | 게임 내 저장·재부팅·로드 |
| 실제 PlayStation 본체 | 미검증 | 본체 모델·광학 매체 경로의 별도 검증 필요 |
| PSP POPS / EBOOT.PBP | 미검증 | 패치 BIN 검증 후 별도 변환 필요 |
| DuckStation 등 다른 PS1 에뮬레이터 | 미검증 | 보고 환영 |
| ODE·모드칩·CD-R 실행 | 미검증 | 부팅 방식과 매체 정보를 함께 기록할 것 |

## 완료한 대표 검증

- 콜드 부팅과 타이틀 표시
- 이름 입력, 일반 메모리카드 저장·로드
- 장시간 자연 플레이와 맵 전환
- MD 상점·재생 화면과 음원
- 애니멀 파일과 주요 메뉴
- 과거 크래시가 발생했던 동굴, 연구실, 라이브, 엔딩 우주선 장면
- 진엔딩, 크레딧, `THANKS FOR PLAYING`, 지연된 숨은 메시지
- 수정한 Mode2/Form1 섹터의 EDC/P/Q ECC
- 최종 이미지의 소유 범위 밖 변경 0바이트

## PSP 또는 다른 에뮬레이터 제보

다음 정보를 포함하면 호환성 표를 근거 있게 갱신할 수 있습니다.

- 한국어 패치 버전과 패치 직후 BIN SHA-256
- PSP 모델, 펌웨어와 POPS 환경 또는 에뮬레이터 이름·버전
- EBOOT.PBP 변환 도구와 설정
- 부팅, 음원, 저장, 맵 전환, MD 재생, 엔딩 여부
- 문제가 생긴 정확한 시점과 재현 순서

PBP 자체 SHA-256만으로는 패치 직전 BIN을 식별할 수 없으므로, 변환 전에
`verify_image.py` 결과를 보존하는 것을 권장합니다.

## 실기 제보

실기에서는 가능하면 다음을 함께 기록해 주세요.

- 본체 SCPH 모델과 지역
- ODE, 모드칩, FreePSXBoot/UniROM 또는 CD-R 등 부팅 방식
- CD-R이면 매체·기록기·기록 속도
- 메모리카드 종류
- 콜드 부팅 횟수와 장시간 플레이 여부

한 본체에서의 성공은 그 환경의 검증 근거이며 모든 PS1 리비전의 보증은
아닙니다.
