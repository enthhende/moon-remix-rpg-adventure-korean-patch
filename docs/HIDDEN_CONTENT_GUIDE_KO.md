# v2.0 숨겨진 콘텐츠 안내

> 이 메뉴에는 본편 결말과 설정에 관한 강한 스포일러가 있습니다.
> 가능하면 본편 엔딩을 본 뒤 열람해 주세요.

## 진입 방법

1. 게임을 콜드 부팅해 `PUSH START` 화면까지 갑니다.
2. `START`를 눌러 원래 Game Start/Continue 화면을 엽니다.
3. 이 화면에서 `SELECT`를 한 번 누릅니다.
4. `*스포일러 주의*`, `*본편 결말 후에 열람 바랍니다*` 아래의
   노란색 `*미사용 개발 자료`를 `○` 버튼으로 고릅니다.
5. `본편 결말을 보셨습니까?`에서 `예`를 선택합니다.

`PUSH START` 화면 자체에서 `SELECT`를 누르는 것이 아니라, `START`
뒤에 나오는 Game Start/Continue 화면에서 눌러야 합니다.

## 메뉴 구성

숨겨진 메뉴에는 다음 네 항목이 있습니다.

1. `보너스 자료관`
2. `용의꼬리(미사용 엔딩)`
3. `소년과 할머니`
4. `타이틀로 돌아가기`

첫 페이지에는 앞의 세 항목이, 다음 페이지에는
`타이틀로 돌아가기`가 표시됩니다. 첫 항목에서 위로 이동하거나 마지막
항목에서 아래로 이동하면 페이지가 바뀝니다. 목록은 위·아래로 순환합니다.

원작의 위험한 디버그 기능을 그대로 공개한 메뉴가 아닙니다. 확인된 자료만
감상할 수 있도록 별도로 만든 읽기 전용 진입 경로이며, 개발 중 사용한
디버그 항목은 공개판에서 제거했습니다.

## 보너스 자료관

보너스 자료관은 16개 자료로 이루어져 있습니다. 이미지 16화면과 한국어
해설 32화면을 합쳐 총 48화면이며, 마지막 FILE16은 이미지만 표시합니다.

| 입력 | 동작 |
|---|---|
| `○`, `→`, `↓` | 다음 해설 화면 또는 다음 FILE |
| `←`, `↑` | 이전 화면 또는 이전 FILE |
| `×` | 자료관을 나가 숨겨진 메뉴로 복귀 |

FILE01 첫 화면과 FILE16 마지막 화면에서는 범위 바깥으로 이동하지
않습니다. 자료관을 나갔다가 다시 들어오면 FILE01부터 시작합니다.

자료관에 음악이나 효과음이 없는 것은 정상입니다. 이미지의 연속 CD 읽기와
화면 복귀 안정성을 우선해 무음 사양으로 완성했습니다.

## 용의꼬리(미사용 엔딩)

디스크에 남아 있던 여러 미사용 장면과 이벤트 프로그램 조각을 조사해 하나의
감상 가능한 흐름으로 재구성했습니다. 완성된 숨은 엔딩 하나의 잠금을 푼
것은 아닙니다.

본편과 같은 방향키와 `○` 버튼으로 진행합니다. 정상적으로 끝까지 보면
원래 타이틀 정리 절차를 거쳐 자동 복귀합니다.

감상을 중단하거나 진행이 불안정해 보이면 물리적인 `START`와
`SELECT`를 함께 눌러 긴급하게 타이틀로 돌아갈 수 있습니다. 입력 자체가
받지 않는 비정상 상태에서는 에뮬레이터나 본체의 리셋을 사용하세요.

## 소년과 할머니

집 밖 장면과 집 안 장면은 별개 분기가 아니라 이어지는 하나의 이벤트입니다.
집 밖에서 시작해 문으로 들어가면 집 안 장면으로 자연스럽게 연결됩니다.

미완성 침대 구석의 불완전한 트리거는 실행되지 않도록 막았고, 남쪽으로
나가면 안전하게 타이틀로 돌아갑니다.

## 저장 데이터 주의

- 숨겨진 자료 모드에서는 일반 게임 저장을 진행하지 않도록 보호했습니다.
- 그래도 중요한 메모리카드 저장은 진입 전에 별도로 백업하세요.
- 서로 다른 패치 버전에서 만든 savestate를 불러오지 마세요.
- 이상이 생기면 게임 내 저장이 아닌 에뮬레이터/본체 리셋으로 종료하세요.
