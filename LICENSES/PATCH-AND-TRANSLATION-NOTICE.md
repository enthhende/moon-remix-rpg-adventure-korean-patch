# 한국어 번역 및 패치 고지

루트의 MIT License는 이 프로젝트가 새로 작성한 적용·검증 도구와 설명
문서에 적용됩니다. GitHub Release의 xdelta 패치와 그 안의 한국어 번역
데이터에는 MIT License를 적용하지 않습니다.

다음 범위의 이용을 허용합니다.

- 개인이 합법적으로 준비한 지원 원본에 패치를 적용하는 행위
- 수정하지 않은 xdelta 패치, 매니페스트, 적용 도구, 라이선스·저작권
  고지를 모두 함께 유지하는 비상업적 재배포
- 공식 GitHub Release 링크의 공유

다음 범위는 허용하지 않습니다.

- 원본 또는 패치된 전체 게임 이미지, BIOS, 메모리카드 덤프와 함께 배포
- 패치나 한국어 번역 데이터의 판매 또는 유료 접근권 제공
- 원작 권리자의 공식 제품이나 승인을 받은 작업인 것처럼 표시
- 제3자 글꼴의 OFL-1.1 조건 제거 또는 변경

이 고지는 원작 게임에 관한 권리를 부여하지 않습니다. 원작 자료에 관한
권리는 각 권리자에게 있으며, 글꼴 유래 데이터에는 OFL-1.1이 계속
적용됩니다.
